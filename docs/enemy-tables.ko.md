# 적 생성 테이블

1. 적 → 테이블에서 이름을 정하고 몹 종류·수량·동면 여부를 행으로 추가합니다. 모든 행을 정해진 수량대로 생성합니다.
2. 이벤트 관리에서 몹 테이블 생성 블록을 추가합니다.
3. 사용할 테이블, 생성할 타일/구역, 횟수·간격·최소 거리를 선택합니다. 처음부터 생성하려면 스테이지 시작 발생 조건에 연결합니다.
4. 무한 반복(횟수0)을 멈추려면 몹 테이블 생성 중지 블록을 사용합니다. 이미 생성된 몹은 남습니다.

테이블 하나는 최대32행, 합계64마리입니다. 등록만으로 생성되지 않으며 동일 테이블을 여러 이벤트에서 재사용할 수 있습니다. 길 정리 목표의 대상으로도 선택할 수 있습니다. 실제 게임 실행은 ES0.6.19 이상이 필요합니다. 기존 생성 그룹은 별도 항목에서 기존 설정을 보존합니다.
