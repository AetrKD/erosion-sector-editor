# 편집기 사용성 개선

- 목표 대상: 종류에 맞는 항목만 표시하고, 타일은 구역·이름·층으로 구분합니다.
- 목표 입력: 필요한 수량/시간만 표시합니다. 기존 터미널 목표 데이터는 유지하지만 새로 만들 수 없습니다.
- 탈출 임무: 메인 완료 설정을 숨기고 탈출 위치·스캔 설정으로 바로 이동합니다. 기존 목표는 보존합니다.
- 저장: 브라우저 임시 저장과 .esfile 다운로드를 구분합니다.
- 화면: 자원·장치 배치로 메뉴를 정리하고 빈 라이브러리, 중복 이벤트 생성과 안내를 제거합니다. 고유 ID는 설정에 있습니다.
- 미리보기: 오른쪽 기본 50%, 35~65% 너비 조절. 속성을 접어 지도 공간을 확보하며 다시 열 수 있습니다.
- 예시: 전력 복구 스캔 목표 후 탈출로 설정을 연결했습니다. 실행에는 실제 NBT 연결이 필요합니다.

검증: 단위 90개, 브라우저 22개 통과. 저장 파일 재해독, 실행 취소, 실제 NBT/Copycat 및 ES 모델 미리보기를 포함합니다.
