# 제작용 콘텐츠 · 0.5.0

크리에이티브 탭은 **ES 건축**과 **ES 아이템**으로 나눕니다.

## ES 건축

- 일반 문 자동 설치기, 보안 문 자동 설치기
- 장비 선택기
- 시설 조명
- 보급 컨테이너

장비 선택기는 E키로 기존 장비 선택 화면을 엽니다. 우클릭으로는 열지 않습니다. `/erosionsector equipment`도 계속 사용할 수 있습니다. 시설 명령어 터미널·임무 단말기·탈출 스캐너를 복구하지 않습니다. 전송 장치 블록도 제거했습니다.

## ES 아이템

- ID 키카드
- 화물 상자
- 탄약 보급 팩
- 체력 보급 팩

화물은 설치할 수 있는 블록 아이템이지만 임무 목표로 운반하므로 아이템 탭에만 표시합니다. 실제 보급함은 설치용 장치이므로 건축 탭에 둡니다. 문서는 아직 구현하지 않았으며 이 분류 변경으로 빈 기능의 시제품을 추가하지 않습니다.

두 탭의 항목은 중복하지 않습니다. 구형 수동 문 구동부와 미구현 센트리·지뢰 설치기·바이오 트래커는 계속 숨깁니다. 새 항목도 등록만으로 탭에 자동 표시하지 않습니다.

블록 아이콘 6종은 실제 블록 모델을 바닐라와 같은 GUI 회전(30°, 225°, 0°), 크기 0.625와 측면 조명으로 표시합니다. 인벤토리·핫바에도 같은 아이콘을 사용합니다.

0.4.26에서 제거한 구형 터미널 3종과 탈출 스캐너 ID는 계속 등록하지 않습니다. 장비 선택기는 새 `erosionsector:equipment_selector` 블록입니다. `/erosionsector lobby`와 `/erosionsector equipment` 명령은 운영자 권한 없이 사용할 수 있고 열린 위치에서 8블록을 벗어나거나 차원을 이동하면 화면이 닫힙니다.

시설 터미널 기믹이 남아 있는 스테이지는 검사·출발 전에 수정 필요 메시지를 표시합니다. 스캔 탈출은 실제 블록 없이 지정한 원형 구역에서 요구 인원과 시간을 만족해 판정합니다. 크기·위치·랜덤·연속 단계는 [스캔 안내](scans.ko.md)를 참고하세요. 기존 사용자 설정·총기 파일과 스테이지 원본은 수정하지 않습니다.
