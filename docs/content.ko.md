# 제작용 콘텐츠 · 0.4.26

ES 크리에이티브 탭에는 현재 사용할 수 있는 9개 항목만 표시합니다.

- 일반 문 자동 설치기, 보안 문 자동 설치기
- 시설 조명
- 화물 상자, 보급 컨테이너
- 텔레포터
- ID 키카드
- 탄약 보급 팩, 체력 보급 팩

구형 수동 문 구동부와 미구현 센트리·지뢰 설치기·바이오 트래커 시제품은 탭에서 숨겼습니다. 이 항목들의 기존 저장 데이터와 내부 등록은 유지합니다. 새 아이템이 등록되어도 자동으로 제작 탭에 추가하지 않습니다.

임무 선택·장비 선택·시설 터미널 및 탈출 스캐너는 블록과 아이템 등록 자체를 제거했습니다. 기존 월드에 설치한 해당 블록과 보유 아이템은 더 이상 사용할 수 없습니다. 다른 블록, 사용자 설정, 총기 설정 파일은 수정하지 않습니다.

임무·장비 선택 화면은 각각 `/erosionsector lobby`, `/erosionsector equipment`로 엽니다. 두 명령은 플레이어가 운영자 권한 없이 사용할 수 있습니다. 열린 위치에서 8블록을 벗어나거나 차원을 이동하면 화면이 닫힙니다. 기존 `/erosionsector terminals` 지급 명령은 제거했습니다. 스테이지 출발은 기존 관리자 명령을 사용합니다.

시설 터미널의 명령 입력 화면과 통신도 제거했습니다. 터미널 기믹이 남아 있는 스테이지는 검사·출발 전에 이름과 수정 필요 메시지를 표시합니다. 편집기에서 터미널 기믹과 연결된 목표·이벤트를 다른 조건으로 변경해야 합니다. 기존 파일을 자동으로 덮어쓰지는 않습니다.

스캔 탈출 기믹은 블록 없이 지정한 위치를 검사합니다. 대원 한 명이 해당 1×1 구역에 서 있고, 생존 동료들이 설정한 반경에 모여 지정 시간 동안 유지하면 탈출합니다. 텔레포터 탈출은 기존처럼 실제 장치와 E키를 사용합니다.
