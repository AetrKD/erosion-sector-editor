# 원형 스캔 · 0.5.0

전송 장치와 스캐너 블록은 사용하지 않습니다. 스테이지 시작 시 지정한 진입 타일의 좌표로 즉시 투하합니다. **진입 스캔은 없습니다.** 일반 스캔과 구조 신호용 탈출 스캔은 블록·엔티티 없이 바닥에 원형 홀로그램으로 나타납니다.

## 편집기에서 만들기

1. 기믹에서 **원형 스캔** 또는 **탈출 지점**을 고르고 배치된 타일 안을 클릭합니다.
2. 소속 타일과 내부 X/Y/Z 좌표를 지정합니다. 좌표는 바닥 셀 기준이며 X/Z의 셀 중앙에 원이 놓입니다. Y는 플레이어 발이 서는 바닥 윗면의 높이입니다.
3. 반경·시간·요구 인원을 지정합니다. 반경은 0.5~16블록이며 지름은 그 두 배입니다. 시간은 0.1~3600초, 요구 인원은 1~16인 이상 또는 생존한 팀 전체입니다.
4. **다음 스캔 단계 추가**로 연속 스캔을 구성합니다. 단계마다 다른 타일·위치·반경·시간·인원수를 지정할 수 있습니다. 앞 단계를 마치면 다음 원으로 이동하고 그 단계의 진행도가 0부터 차오릅니다.
5. `.esfile`로 저장합니다. 타일 NBT는 계속 외부 폴더에서 참조하며 별도의 스캔 블록이나 리소스팩을 넣을 필요가 없습니다.

일반 스캔은 ‘시작 시 자동 활성화’를 끄고 이벤트로 시작할 수 있습니다. 탈출 스캔은 필수 목표가 끝나면 기본적으로 활성화됩니다. 자동 활성화를 끄면 이벤트에서 제어할 수 있습니다.

## 판정과 진행

원 안의 참가자 수가 요구 인원을 충족하면 서버 기준으로 진행됩니다. 원 밖으로 나가거나 인원이 부족해지면 **현재 진행도를 그대로 유지하고 정지**합니다. 다시 조건을 만족하면 이어서 진행합니다. 지금은 감소·자동 초기화 스캔 타입을 제공하지 않습니다.

판정은 플레이어 발 위치의 수평 거리와 높이를 사용합니다. 바닥 기준 위아래 **1블록까지 포함**하며, 다른 층·벽 너머·임무에 참가하지 않은 플레이어·관전자·사망자는 집계하지 않습니다. ‘팀 전체’는 살아 있고 접속 중인 참가자 전원을 뜻합니다.

원형 테두리와 진행 호는 상태에 따라 청록색 또는 주황색으로 표시합니다. 가까운 스캔은 화면에 이름·단계·퍼센트·현재/요구 인원도 표시합니다. 서버가 판정하고 모든 참가자에게 같은 상태를 전송합니다. 클라이언트는 화면 표시만 부드럽게 보간합니다.

## 랜덤 위치

위치 방식에서 **연결된 바닥에서 랜덤**을 고릅니다. 입력한 좌표는 랜덤 검색의 기준 위치가 됩니다.

- 선택한 타일과 지정한 정수 높이의 평평한 바닥 안에서 찾습니다.
- 기준 위치와 연결된 바닥이며 벽에 가리지 않는 후보만 선택합니다.
- 원의 중심뿐 아니라 **원 전체 반경**을 검사합니다. 바닥 구멍·낭떠러지·타일 밖·벽·두 블록 높이의 공간 부족을 피합니다.
- 조건에 맞는 위치가 없으면 다른 방으로 넘기거나 원을 줄이지 않고 오류를 안내합니다. 기준 위치나 반경을 조정해야 합니다.
- 스캔 시작·재시작과 다음 단계 진입 시 현재 블록 상태로 선택합니다. 매 프레임 위치를 바꾸지 않습니다.

현재 랜덤 배치는 보수적으로 **정수 높이의 평평하고 온전히 지지되는 바닥**을 요구합니다. 계단·반블록·기울어진 표면까지 자동으로 따라 그리는 기능은 없습니다. 그런 위치는 직접 지정할 수 있습니다.

## 문·목표·이벤트 연결

블록 이벤트의 **스캔 상태가 바뀌면**은 시작·다음 단계·전체 완료를 구분합니다. **스캔 제어**는 시작·일시정지·다시 진행·초기화 후 시작·종료를 지원합니다. 진행 중인 스캔에 시작을 다시 보내도 진행도를 지우지 않습니다. 초기화는 명시적으로 선택해야 합니다.

보안 문에 연결하는 예:

1. 문을 잠긴 상태로 설정합니다.
2. ‘보안 문을 열려고 하면’ → ‘스캔 제어: 시작’을 연결합니다.
3. ‘스캔 상태: 전체 완료’ → ‘문 제어: 이쪽 면 잠금 해제’를 연결합니다.
4. 기존 규칙대로 잠금 해제된 보안 문의 패널에서 E를 1초 유지해 엽니다.

일반 스캔은 임무 목표의 **스캔 완료** 대상으로도 사용할 수 있습니다. 조명 변경·알람 시작·다른 스캔 활성화 같은 실행 블록도 같은 완료 이벤트에 연결합니다. 구조 신호용 탈출 스캔의 마지막 단계를 마치면 임무 성공으로 처리하고 출발 전 위치로 복귀합니다.

현재 시설 터미널 블록은 제거된 상태입니다. 새 터미널을 구현하면 같은 스캔 시작 실행 블록을 명령어 완료 이벤트에 연결할 수 있도록 이벤트 구조를 유지했습니다.

기믹당 최대 64단계, 스테이지 전체 최대 128개 스캔·512단계입니다. 바닥 연결 정보와 반경 검사 결과는 선택 중 재사용하고, 상태 동기화는 최대 초당 10회, 그림은 매 프레임 처리합니다. 지형의 월드 광원을 바꾸지 않으며 Iris/ES 어둠 처리 뒤에 발광 표시를 합성하고 기존 깊이로 벽·바닥 차폐를 유지합니다.
