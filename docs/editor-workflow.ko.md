# 편집기 메뉴와 제작 순서

위쪽의 **배치 지도 / 타일 미리보기 / 이벤트 편집**은 언제든 전환할 수 있는 작업 메뉴입니다. **임무 목표**에서 완료 조건을 정하고 **모의 실행**으로 이벤트 연결을 확인합니다. 선택·배치와 평면·입체 도구는 배치 지도에서만 표시합니다. 실행 취소·다시 실행은 모든 작업에서 공통으로 사용할 수 있습니다.

**타일 미리보기**에서는 타일 라이브러리의 설계도를 눌러 개별 NBT를 확인합니다. 이 화면에서 타일을 누르는 동작은 지도 배치로 전환하지 않습니다. **이벤트 편집**은 이벤트 목록·블록 검색·조립 영역으로 구성합니다. 발생 조건과 실행 동작을 따로 표시하고, 템플릿·이벤트 복제·블록 접기로 긴 흐름을 정리할 수 있습니다. [이벤트 작업실 사용법](event-blocks.ko.md).

스테이지 이름 옆의 **제작 체크리스트**는 현재 작업을 기준으로 남은 단계를 표시합니다. 각 항목을 누르면 해당 작업으로 이동합니다. 메뉴를 방문하는 것만으로 프로젝트를 변경하지 않습니다.

1. **타일 설계도 준비**: `assets/tile/` 폴더를 연결하면 타일셋 폴더별로 가져옵니다. NBT 하나를 가져오거나 원본 없는 설계용 타일부터 시작할 수도 있습니다.
2. **타일 배치와 문 연결**: 라이브러리에서 지도로 끌어 놓습니다. 타일을 고른 후 지도에 클릭해도 됩니다. 배치 중인 타일 이름과 방향을 지도 위에서 확인하고, R로 회전하거나 취소 버튼·Esc로 취소합니다.
3. **시작점과 탈출 지점**: 기믹 라이브러리의 ‘진입과 탈출’에서 각각 하나를 타일 안에 놓습니다. 기믹은 진입과 탈출 / 스캔과 이벤트 / 보급과 목표 / 적 배치로 나뉩니다.
4. **임무 목표 정하기**: 필수 목표 완료 후 탈출하거나 탈출 자체를 목표로 선택합니다. 알람·문·조명·연속 스캔 등의 연동은 이벤트 편집에서 구성합니다.
5. **실행 전 확인**: 검사 결과의 항목을 눌러 문제 대상에 접근합니다. 게임 실행 전에는 원본 설계도와 게임 내 충돌·모드 동작도 확인하세요.

**파일** 메뉴에는 새 스테이지, .esfile 불러오기·저장, 타일 폴더 연결, NBT 가져오기, 예시와 사용 가이드가 모여 있습니다. 좁은 화면에서도 같은 메뉴를 사용할 수 있습니다. 메뉴는 Esc 또는 바깥을 누르면 닫힙니다. 라이브러리 분류 탭은 방향키·Home·End로도 전환할 수 있습니다.

폴더 연결은 파일을 읽는 작업이며 원본을 수정하지 않습니다. **스테이지 저장**으로 내려받은 `.esfile`을 작업 폴더의 `stage/`에 보관하세요. 자동 저장은 이 사이트 주소의 브라우저 복원본이므로 별도 파일 백업이 필요합니다. 타일 NBT는 `.esfile`에 넣지 않고 기존 `assets/tile/타일셋/타일.nbt` 경로로 참조합니다.

파일 형식은 변경하지 않았습니다. 기존 스테이지 파일을 그대로 열 수 있습니다. 이번 변경에서 데이터 검사 84개와 화면 검사 59개가 통과했습니다(기록 DB API 검사 2개 제외). 화면 검사에는 새 작업 → 실제 NBT 폴더 연결 → 배치 → 시작점·탈출 → 임무 방식 → .esfile 저장, 좁은 화면·드래그 배치·실행 취소·미리보기·이벤트 검색·템플릿·복제·블록 접기가 포함됩니다.
