# 실제 장비 거치대 · 0.6.4

세 장비 선택기를 실제 장비를 고정 거치하는 형태로 교체했다. TaCZ 작업대의 두꺼운 지지 구조·접힌 금속 테두리·안쪽으로 들어간 패널·절제된 재질 표현을 참고하되 ES 전용 형상과 텍스처를 직접 제작했다. 작업대 상판이나 석상 형태는 가져오지 않았다. 석상은 실제 총기의 FIXED 렌더링 호출만 참고했다.

## 구성

- 근접: 네더라이트 검·철 검·철 도끼·다이아몬드 검·다이아몬드 도끼의 실제 아이템 모델 5개.
- 총기: 설치된 TaCZ 1.1.8-hotfix-r7의 AK-47·M4A1·HK MP5A5·M870·Glock 17·Desert Eagle 실제 모델 6개. TaCZ가 없는 환경에서는 총기 칸만 비운다. 대체 가짜 총기나 석상 엔티티를 생성하지 않는다.
- 도구: 실제 sentry_tool/mine_tool/tracker_tool 아이템을 표시한다. 이 아이템들도 ES 전용 입체 모델로 만들었으며 손·인벤토리·거치대가 같은 아이템 모델을 사용한다. 도구의 실제 배치/탐지 기능을 새로 구현한 것은 아니다.
- 근접은 가죽 받침이 있는 독립 세로 거치판, 총기는 2단 총열/개머리판 지지대와 권총 칸, 도구는 폭이 넓은 3개 도킹 칸이다. 무기를 다른 형태로 변형하지 않고 위치·회전·균일 배율로 배치한다.

현재 5×1×3 점유·4방향·E 선택·단일 드롭은 유지한다. 기존 rack=false의 3×1×2 선택기도 작은 외형 안에 새 거치대를 표시하며 주변 건물을 확장하지 않는다. 현재 거치대는 재설치하지 않아도 변경된다. 장비 전시는 인벤토리가 아니며 물건을 빼거나 복제할 수 없다. 선택 결과에 따라 거치 목록을 계속 바꾸지 않는다.

## 원본과 비용

- tools/rack-assets.py: 명시적인 ES 형상/UV/직접 그린 아틀라스 원본. tools/selector-models.mjs는 이 도구의 진입점이다.
- assets-source/equipment-racks/: 세 거치대와 세 도구의 편집 가능한 .bbmodel 원본. 외부 총기·바닐라 아이템 아트는 복사하거나 포함하지 않는다.
- assets/erosionsector/equipment-displays.json: 그룹별 실제 아이템/총기 ID, 위치, 균일 배율, 고정 각도. 향후 장비 추가 시 여기서 배치를 변경한다. 리소스 재로딩에 대응한다.
- 거치대 본체는 청크에 굽는 정적 모델이다. 실제 장비만 루트 1개에서 그린다. 프레임 전체나 15개 셀 각각을 BER로 다시 그리지 않는다. 전시 엔티티·서버 티커·아이템 저장/방송은 없다. 아이템 스택은 월드/리소스별 캐시를 재사용하고 로그아웃 때 해제한다.
- 전체 구조 AABB를 사용해 루트 셀만 화면 밖일 때 사라지는 것을 방지하며, 실제 장비 표시는 구조 표면에서 32블록 이내로 제한한다. TaCZ 자체 FIXED/LOD 경로를 사용한다. 석상의 sin(time/500)*0.1 이동·자동 회전·애니메이션 상태 머신을 호출하지 않는다. 기존 TaCZ 1인칭 렌더러는 렌더 후 cleanAnimationTransform을 수행한다.

## 시설 조명 제거

facility_light와 white/red/blue/green의 일반/어두운 8개 재료를 포함한 ES 시설 조명 9개를 블록·아이템 등록, 건축 목록, 모델·텍스처·전리품·Copycat 허용 태그에서 제거했다. give/setblock으로도 새로 얻지 못한다. 다른 모드 조명·손전등 엔진/설정은 변경하지 않는다.

기존 월드를 이 버전으로 열면 제거된 ES 조명은 공기로 처리되며 기존 조명 아이템도 사용할 수 없다. 원본 월드·타일 NBT 파일을 도구로 일괄 수정하지 않는다. 예전 스테이지의 조명 이벤트/초기 상태 데이터는 파일 계약 보존을 위해 읽지만, 사라진 조명이나 다른 모드 조명을 자동 제어하지 않는다.

공개 웹 리소스에는 새 정적 거치대 외형과 제거 목록을 반영한다. 이전 로컬 리소스 묶음이 제거된 ES 조명을 되살리지 않게 한다. 실제 장비 전시는 게임의 아이템 렌더러에서 그리므로 웹의 정적 블록 미리보기에서는 거치대 프레임을 표시한다. 외부 실제 장비 모델을 공개 묶음으로 복사하지 않는다.
