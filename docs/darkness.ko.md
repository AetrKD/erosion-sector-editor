# 광원 중심의 어두운 환경 — Erosion Sector 0.4.23

## 효과 켜기와 끄기

메인·일시정지 메뉴의 **ES 설정 → 조명·밝기 효과 → ES 조명·밝기 효과 사용**에서 통합 효과를 켜거나 끌 수 있습니다. 설정을 적용하면 재접속 없이 반영됩니다. 기본값은 켜짐이며, 끄면 ES 어둠 필터·손전등 조명·ES 총구 조명과 추가 화염 표시를 중단하고 관련 렌더링 자원을 해제합니다. 다시 켜면 기존 밝기·거리와 개별 활성화 설정대로 동작합니다.

어둠만 끄고 싶으면 **주변 어둠 → 주변 어둠 사용**을 끄세요. 손전등·총구 조명은 별도로 유지할 수 있습니다. 통합 스위치는 클라이언트 시각 효과를 제어하며 실제 시설 조명, 문, 서버의 손전등 상태·몹 노출 판정, TaCZ 자체 1인칭 불꽃과 다른 모드의 조명은 바꾸지 않습니다.

설정 파일에서는 `minecraft/config/erosionsector-client.toml`의 다음 항목을 사용합니다.

```toml
[lighting]
enabled = true
```

0.4.23에서는 외부 모드 없는 기본 클라이언트와 TaCZ 1.1.8-hotfix-r7·Create 6.0.10·Iris 1.8.14-beta.1·Sodium 0.8.13·Complementary Reimagined r5.9.3 조합에서 켜기 → 끄기 → 다시 켜기를 확인했습니다. 비활성 중 렌더 대상·광원 볼륨·그림자 자원 해제, 총구 효과 정리·새 효과 생성 차단·재활성화, 개별 설정과 손전등 상태 보존을 검사하고 실제 화면을 캡처했습니다.

## 어둠 처리

광원이 닿지 않는 월드 표면은 기본 밝기의 0.2%만 남겨 거의 검게 표시합니다. 실제 블록 광원과 햇빛이 닿는 곳은 밝기를 유지하고, Erosion Sector 손전등·총구 화염은 어둠 처리 이후 별도로 더합니다. 따라서 환경을 어둡게 해도 손전등과 총구 조명까지 함께 어두워지지 않습니다. 어둠 모드는 기본 활성화입니다.

바닐라 화면과 Iris 셰이더팩의 최종 화면에 같은 처리를 적용합니다. 셰이더가 동굴의 기본 주변광이나 자동 노출로 장면을 밝히더라도, 실제 빛이 없는 표면을 어둡게 만듭니다. 셰이더팩 ZIP·선택·켜짐 상태와 Minecraft 밝기 설정은 변경하지 않습니다. 화면 전체에 검은 필터를 씌우는 방식과 달리, 조명 주변은 구분해서 표시합니다.

블록 광원은 Minecraft 조명 엔진의 기존 데이터를 읽습니다. 횃불·용암·조명 블록 등 실제 빛이 퍼진 위치를 사용하며, 새 광선 검사를 하거나 월드에 광원 블록을 설치하거나 지형을 다시 밝히지 않습니다. 빛이 강하면 원래 표면 밝기를 유지하고, 약해지는 구간은 공간 보간으로 점차 어둡게 만듭니다. 직접적인 낮 햇빛은 유지하지만 바닐라의 밤 기본 밝기 하한은 제외합니다. 밝기 8 이상은 원래 표시를 유지하며, 완전한 무광원에서만 가장 어두워집니다.

GPU에 카메라 주변 256×128×256블록의 빛 데이터를 보관합니다. 블록 광원·햇빛 데이터 약 16MiB와 작은 유효성 표를 사용하고, 이동할 때 기존 영역을 재사용합니다. 각 타일에 정확한 월드 구역 좌표를 확인하므로 음수 좌표나 순간이동 때 이전 구역의 빛이 새 위치로 새지 않습니다. 실제 데이터가 달라진 부분만 업로드하며, 기본 프레임당 CPU 갱신 예산은 1ms입니다. 새 구역에 들어가거나 조명을 바꿨을 때 해당 빛 정보가 채워지는 동안 짧은 지연이 있을 수 있습니다. 손전등·총구 화염의 매 프레임 계산은 이 캐시를 기다리지 않습니다.

캐시 범위를 벗어난 표면은 카메라 주변의 햇빛 노출을 근거로 멀리 있는 야외의 낮 밝기를 근사합니다. 범위 밖의 개별 횃불·조명 위치까지 추적하지 않습니다. 시설 내부를 중심으로 한 구현이며, 매우 넓은 야외·큰 수직 공간에서는 이 범위를 고려해야 합니다.

`minecraft/config/erosionsector-client.toml`에 다음 항목이 자동 추가됩니다.

```toml
[darkness]
enabled = true
unlitBrightness = 0.002
fullLightLevel = 8.0
respectNightVision = true
budgetMicros = 1000
```

`unlitBrightness = 0.0`은 완전한 검정입니다. `enabled = false`는 기존 밝기를 복원합니다. 바닐라 야간 투시 효과는 기본적으로 어둠 처리를 우회하며, 필요하면 `respectNightVision = false`로 바꿀 수 있습니다. 손전등의 `directLighting`을 끄더라도 어둠 모드는 별도로 유지됩니다.

HUD·메뉴·하늘과 별도 투영을 쓰는 1인칭 손·총기는 이 월드 표면 필터에서 제외합니다. 깊이를 기록하지 않는 투명 물체·파티클이나 셰이더팩 고유의 화면 왜곡·피사계 심도에는 기존 자체 조명 엔진과 같은 제한이 있습니다. 월드 광원 데이터 없이 셰이더 재질만 발광하는 표면, 다른 모드의 화면 전용 동적 조명은 어둡게 될 수 있습니다. Erosion Sector가 추가한 팀원 화염은 발생 위치 근처에서 표시를 보존합니다.

이 모드는 클라이언트 시각 효과입니다. 실제 블록 밝기·적 생성·몹 AI·서버의 손전등 노출 판정과 사용자 감마 값을 바꾸지 않습니다.

통합 검사 61개 중 어둠 관련 4개는 음수 좌표의 캐시 배치, 밀폐된 방의 실제 광원 데이터 일치, 빈 하늘 구역과 미로드 구역, ScalableLux가 반환하는 동일 내용 복사본의 재사용을 검사합니다. GPU 검사는 밝게 보정된 장면의 무광원 어둠 처리, 블록 조명·낮/밤 햇빛, 손전등·총구 조명 복원, 큰/음수 좌표와 캐시 재사용, 비활성화 시 원본 복원을 검사합니다. 실제 게임에서 셰이더팩을 켠 외형과 FPS를 직접 측정한 검증은 아직 없습니다.

## 0.3.23 실내 밝기 경계 수정

가까운 바닥의 화면 픽셀 면적이 작아지면 기존 표면 방향 계산이 다른 계산으로 바뀌어, 조명이 있는 실내 아래쪽에 수평 밝기 경계가 생겼습니다. 표면을 따라 얻은 두 방향을 먼저 정규화한 뒤 면 방향을 계산하도록 바꿔 해상도·거리에 따른 판정 전환을 제거했습니다. 무광원 어둠의 세기와 월드 광원 데이터는 유지합니다.

GPU 재현 장면에서 기존 코드가 1920×1080의 같은 조명 바닥에 밝기 차이를 만들었고, 수정 후 1920×1080과 3840×2160에서 경계 없이 원래 바닥 밝기를 유지하는지 확인했습니다. 기존 손전등·총구·어둠·Iris 입력 검증도 통과했습니다. 이번 수정은 GPU 셰이더 변경이며, 실제 게임 화면에서의 확인은 별도로 필요합니다.

0.3.24는 조명이 있는 시설을 탐사하기 쉽도록 `fullLightLevel` 기본값을 12에서 8로 낮췄습니다. 약한 조명을 받는 표면은 덜 어두워지고, 광원이 전혀 없는 표면의 `unlitBrightness = 0.002`는 유지합니다. 셰이더 계산과 추가 광선 검사 수는 바꾸지 않습니다.
