# 편집기 정리·공통 상호작용·컨테이너 (0.6.2)

2026-10-20 사용자 승인 작업. 실제 설치·배포·검사 결과는 루트 PROJECT_CONTEXT.ko.md의 최근 기록을 확인한다.

## 웹

- 파일/저장 머리글 → 스테이지 이름·ID·검사 상태 → 6개 작업 메뉴 → 편집 공간 순서다.
- 하단 장식 바·중복 예시 버튼·상시 단축키/규격/자동 저장 설명을 제거했다. 오류·현재 값·연결 상태와 사용자가 작성한 임무 설명은 유지한다.
- 일반 메뉴·항목에는 도움말을 붙이지 않는다. 목표 완료 규칙·문 연결 거리·랜덤 스캔·보급 분할·챕터 ID·조건 반복·로컬 리소스 연결처럼 결과를 오해하기 쉬운 부분에만 ⓘ 버튼을 둔다. 키보드 Enter로 열고 Esc 또는 바깥 클릭/닫기로 닫는다. 도움말이 열렸을 때 배경 편집 단축키는 동작하지 않는다.
- 타일 미리보기는 타일 배치 메뉴에서만 지도 오른쪽 절반을 사용한다. 지도 도구·층 선택도 왼쪽 절반에 맞춘다. 다른 메뉴에서 분할 공간까지 숨기고, 돌아오면 켜짐 상태를 유지한다. 좁은 화면은 위아래 배치다.
- 평면 지도 좌표는 아래 X/왼쪽 Z의 고정 눈금 띠에 표시한다. 화면 이동·확대에 맞춰 값과 간격만 바뀌며 타일 위를 떠다니지 않는다.
- 모의 실행 버튼·호출·대화상자 구현을 제거했다. 이벤트 실행 규칙의 단위 검사에 쓰는 순수 엔진은 유지하며 제품 UI에서는 가져오지 않는다.
- 현재 기능과 맞지 않던 화물/보급/이벤트 안내를 갱신했다. 개인 파일·게임 기록의 서버 동기화는 추가하지 않았다.

## 인게임 공통 UI와 상호작용

- 하단은 안내 → 높이5의 반투명 무테 게이지 → 아이템 이름 → HP/손전등/ST → 핫바 순서다. 폰트 줄 높이를 공유하며 스캔 상태와 일반 상태 알림도 위쪽 별도 위치를 사용한다.
- 큰 GUI 배율에서 스캔 창이 조준점과 겹치면 창을 왼쪽으로 옮긴다. 장비 카드 크기 규칙은 보존한다.
- ES 상호작용은 눈에서 대상 표면/몸체까지 2.5블록이다. 보급 대상의 몸체는 기존 0.1블록 여유를 유지한다. 바닐라 건축·채굴/무기 사거리를 바꾸지 않는다.
- 화물 내려놓기는 실제 지지 가능한 바닥 윗면과 빈 배치 칸을 바라볼 때만 안내·허용한다. 벽/천장/공중/물속/충돌 공간은 불가다. CarryOn의 실제 배치에도 같은 검사를 적용한다.
- 보급품은 플레이어에게 사용한다. 서버가 체력/예비탄 보급의 실질 효과와 바라보는 대상을 확인해 가능한 안내만 보낸다. 대상 부재·거리/시야 이탈·회복 불필요·장비 변경·기절은 사용 취소/무소비다.
- 좌/우 마우스 안내는 해당 버튼을 밝힌 전용 실루엣으로 표시한다. 실제 키 설정을 따르며 다른 키로 바꾼 경우 해당 키를 표시한다. E 안내는 키+행동 형식이다.

## 컨테이너

- 소형1칸(1×1×1), 중형3칸(1×1×2), 대형5칸(2×1×2)의 점유·용량은 그대로다. 기존9칸도 물품과 호환을 유지한다.
- 새/기존 미개봉 컨테이너는 닫힘 → E 1초 유지 → 약0.6초 열림 애니메이션 → 열린 상태다. 키 해제·거리/시야 이탈·기절은 미완료 열기를 취소한다.
- 열린 후 E를 다시 누르면 수납 화면에 접근한다. 한 번 연 컨테이너는 자동으로 닫지 않는다. 모든 부분/플레이어가 동일한 루트 상태와 수납을 공유한다. 재접속·월드 저장 후에도 열린 상태와 실제 물품을 유지한다.
- 소형은 위쪽 뚜껑, 중/대형은 위로 수납되는 전면 셔터다. 전용 속빈 몸체·선반·칸막이를 제작했다. 대형의 윗칸은 넓은 한 칸으로 총5칸이다. 구형9칸은 새 디자인으로 강제 재설치하지 않는다.
- 닿는 표면을 합친 후 외부 면만 만들고 청크 셀로 나눠 겹친 면을 제거한다. 원본 생성기는 lobby-mod/tools/supply-crate-assets.py다. 공통 재질은 tools/structure-assets.py의 ES 직접 제작 PNG를 쓴다.
- 본체는 정적 청크 모델이며 뚜껑/셔터만 동적으로 그린다. 루트 한 곳에서32블록 이내의 움직이는 부분, 열린 뒤16블록 이내의 실제 수납 물품만 그린다. 닫힌/먼 곳의 내용물은 그리지 않고 장식용 드롭 엔티티도 만들지 않는다.
- 웹용 리소스 생성기는 정지한 닫힘 모습에 전용 뚜껑을 합친다. 게임용 정적 몸체와 동적 부품이 중복되지 않는다. 외부 원본 리소스 공개 금지와 로컬 .esresources 정책은 유지한다.

## 검증 범위

서버에는 열기 취소/공유 상태/저장 복원·거리 경계·바닥/벽/물 배치 제한을 추가했다. 클라이언트는 보이는 전용 개발 월드에서 기본 및 설치된 전체 조합을 검사한다. GUI2/3의 스캔/일반 알림을 함께 보이는 검사는 UI 배치용 합성 스냅샷이며 실제 스테이지 완료 검증을 대체하지 않는다. FPS 개선 수치는 측정하지 않았다.
