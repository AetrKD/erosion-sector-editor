# 컨테이너 재설계 (0.6.3)

2026-10-20 사용자 요청: 소형·중형·대형을 서로 다른 디자인과 전용 텍스처로 다시 만들고, 개봉 대기 없이 상호작용 키로 수납 화면을 연다. 0.6.2의 개봉 상태·애니메이션 정책을 대체한다.

- 소형: 아이보리/주황 하드케이스, 낮은 몸체·검은 모서리 보호대·상부 손잡이·앞 잠금장치. 1칸, 한 블록 점유.
- 중형: 올리브 수직 보급함, 받침·상부 캡·환기구·긴 손잡이·힌지. 3칸, 높이2블록.
- 대형: 청회색 운송함, 양문 외형·중앙 잠금장치·강화 프레임·아래 손잡이. 5칸, 너비2/높이2/깊이1블록.
- 각각 textures/block/containers/small.png, medium.png, large.png의 별도256×128 아틀라스를 쓴다. 색만 바꾼 공통 재질이 아니라 각 크기의 면별 패널/띠/환기/하드웨어 그림을 따로 작성했다. 바닐라/외부 자산 차용 없음.
- 원본은 tools/supply-crate-assets.py다. 표면 합집합에서 보이는 면만 만들고 전역 좌표의 UV를 유지한 채 점유 셀로 분할한다. 재질/블록 분할 경계에서 같은 패널을 반복하거나 겹친 면을 만들지 않는다.
- E 한 번으로 즉시 수납 화면을 연다. 한 번 개봉/1초 유지/열림 애니메이션/개봉 게이지/월드에 내부 물품을 별도 렌더링하는 기능은 제거했다. 컨테이너는 전부 정적 청크 모델이다.
- 구형9칸도 E 즉시 사용이다. 이전 Opened/OpenedAt 저장값은 무시하며 실제 보관 물품·용량·다중 블록 루트 공유·단일 드롭·2.5블록 거리/시야 규칙을 유지한다. 기존 구조물 재설치 불필요.
- 수납 내용은 수납 화면의 기본 동기화로 전달한다. 내용물 변경 때 외형을 다시 굽거나 전체 물품을 월드 모델용으로 방송하지 않는다.
- 웹 미리보기도 같은 정적 모델을 사용한다. 별도 닫힘 뚜껑 합성은 제거했다. ES 최신 리소스 우선/외부 리소스 로컬 연결 원칙은 유지한다.
