# 알람·스캔 편집 및 대형 타일 응답 개선 · 2026-10-23

- 블록 메시 생성은 module Worker에서 수행하며 Float32Array 버퍼를 전송한다. 새 작업은 이전 Worker를 종료하고 이전 결과를 폐기한다. 높이 입력90ms 병합, 기존48MiB 메시 캐시/Copycat·연결 텍스처 계약 유지.
- 편집 draft는 immutable base64 NBT/점유 마스크 문자열을 structuredClone 대상에서 분리하고 재연결한다. 수정 가능한 타일·자산 메타데이터는 독립 복사하여 undo/redo를 보호한다. 프로젝트 파일 형식·IndexedDB 저장 계약 유지. 합성8MiB NBT+1MiB 점유 문자열,9회 중앙값: 일반복사7.26ms/draft복사0.04ms. 전체 입력 지연 수치가 아니다.
- 알람 생성·스피커 타일은 지도 클릭/키보드 Space·Enter로 복수 선택하고 검색·구역·층 필터를 제공한다. 필터에 숨겨져도 선택은 유지하고 전체 선택 수를 표시한다. 원본 체크박스 제출과 동일한 배열로 저장한다.
- 알람/스캔 삭제는 이벤트·목표·구형 연결 사용처를 먼저 표시한다. 참조가 있으면 같은 종류의 대체 대상을 선택해야 삭제하며 참조 교체와 삭제를 한 번의 undo로 되돌린다. 없는 대상을 자동 삭제하거나 연결을 암묵적으로 끊지 않는다.
- 스캔 XYZ 입력 상한은 선택 타일 치수에 맞추고 로컬 평면 클릭으로 X/Z 정수 좌표를 지정한다. Y는 별도 입력. 기존 지도·단계 설정을 유지한다. 미니 지도는 위치 선택 도우미이며 실제 바닥 지원/충돌은 게임이 최종 판단한다.
- 단위96개/브라우저11개 통과. 기존 저장 문구 테스트를 현재 문구에 맞췄고, 모달이 닫힌 후 남는 입력 리스너는 AbortController로 정리했다. 실제 자동 리소스→Worker→WebGL, 저장·재열기, undo/redo, 알람 지도·검색 선택 보존, 스캔 위치, 참조 교체 삭제/undo 검증. 서버API나 인증/DB 변경 없음.
