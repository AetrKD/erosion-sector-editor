# 지도 편집과 이벤트 모의 실행

이 기능은 편집기에서 동작하며 기존 모드 0.5.0과 같은 `.esfile` 형식을 사용합니다. 게임 모드 파일 교체는 필요하지 않습니다.

## 라이브러리에서 끌어 배치하기

타일 또는 기믹 카드를 지도로 끌어 놓으면 새로운 항목 하나를 배치합니다. 클릭으로 선택한 뒤 지도를 클릭하는 기존 방식도 사용할 수 있습니다.

- 타일: 마우스 위치를 타일의 X/Z 시작점으로 삼고 1블록 단위로 맞춥니다. 현재 선택한 구역과 층에 배치합니다. 타일을 클릭하고 R로 방향을 정한 뒤 끌면 그 회전을 사용합니다.
- 기믹: 현재 층에 있는 타일 내부에 놓습니다. 회전된 타일도 내부 좌표로 변환합니다. 기본 높이는 해당 층 바닥에서 1블록 위이며 정확한 높이는 속성에서 수정합니다.
- 평면·입체 보기 모두 지원합니다. 입체 보기에서는 보이는 윗면이 아니라 **층 탭에서 선택한 8블록 층**의 평면을 기준으로 배치합니다. 화면에 표시되는 층을 확인하세요.
- 초록색 테두리와 안내는 배치 가능, 빨간색은 타일 겹침·타일 밖 등으로 배치 불가를 뜻합니다. 실제 블록 겹침은 연결된 설계도 점유 정보를 사용하고, 원본이 없으면 타일 전체 범위로 검사합니다. 상자·컨테이너는 알려진 블록 점유와 기존 상자 위치도 확인합니다.
- 지도 밖에 놓거나 Esc로 취소하면 프로젝트는 바뀌지 않습니다. 배치 한 번은 실행 취소 한 번으로 되돌립니다.
- 드래그 배치는 새 항목을 추가하는 기능입니다. 이벤트 블록 끌기와 구역 트리의 타일 이동은 기존 기능으로 유지됩니다.

## 스캔을 지도에서 편집하기

1. 기믹 목록에서 원형 스캔 또는 탈출 지점을 선택합니다.
2. 속성 맨 위의 `1단계`, `2단계` 등으로 편집할 단계를 고릅니다. 해당 층과 타일로 이동하고 확대합니다.
3. 원 중심의 번호를 끌면 위치가 블록 단위로 바뀝니다. 같은 높이에 있는 다른 배치 타일로도 옮길 수 있습니다.
4. 선택한 원 오른쪽의 사각 손잡이를 끌면 반경이 0.5블록 단위로 바뀝니다. 허용 범위는 0.5~16블록입니다.
5. 정확한 높이·시간·인원·위치 방식은 기존 속성 입력으로 설정합니다. 드래그 한 번은 실행 취소 한 번으로 복구할 수 있습니다. 타일 밖으로 끌거나 Esc로 취소하면 적용하지 않습니다.

같은 층의 연속 단계는 번호와 점선으로 이어집니다. 다른 층의 단계는 단계 버튼으로 이동합니다. 랜덤 원은 실제 생성 위치가 아닌 탐색 기준 위치를 뜻합니다.

## 랜덤 위치의 바닥 예상

타일 폴더를 연결하면 선택한 랜덤 단계에 대해 초록색 후보 바닥과 붉은색 제외 바닥을 표시합니다. 기준점과 연결된 같은 높이의 바닥을 탐색하고, 원 전체의 크기·벽·구멍·타일 경계·기준점에서의 직선 통과 여부를 고려합니다. 후보가 없으면 속성에 0곳으로 표시됩니다.

이것은 설계도의 비공기 블록을 바탕으로 한 보수적인 예상입니다. 반블록·사다리 등 모드 블록의 정확한 지지면·충돌 모양, 움직이는 문과 다른 타일에 의한 방해는 게임에서 최종 판정합니다. 초록색이 게임 실행 성공을 보증하지는 않습니다. 원본이 연결되지 않았으면 후보 판정을 표시하지 않습니다.

드래그 중에는 후보 바닥을 잠시 숨기고, 놓으면 새 위치·반경으로 계산합니다. 바닥 경로를 캐시해 지도를 움직일 때마다 다시 계산하지 않습니다.

## 이벤트와 대상 오가기

지도에서 문 연결선을 선택하거나 타일·기믹·구역을 선택하면 속성 아래에 `연결된 블록 이벤트`가 표시됩니다. 발생 조건·검사 조건·제어 대상으로 참조하는 이벤트를 구분합니다. 이벤트를 누르면 해당 블록을 강조해서 보여줍니다.

이벤트 블록의 대상 선택 아래 `대상 위치 보기`로 지도에 돌아갈 수 있습니다. 속성 위의 `보고 있던 이벤트로 돌아가기`로 편집을 이어갑니다. 문은 이쪽 면과 반대쪽 면의 잠금 조건을 구분하며 `반대편 문 보기`로 전환합니다. 대상 이름에는 구역 번호와 하위 구역이 함께 표시됩니다.

## 모의 실행

상단의 `모의 실행` 또는 이벤트 작업실의 같은 버튼으로 엽니다. 열 때 현재 프로젝트의 복사본으로 스테이지 시작 이벤트를 실행합니다. 문은 닫힘, 타일 조명은 켜짐을 초기 가정으로 사용합니다. 실제 설계도에 설치된 조명의 초기 모드나 개별 문 블록의 내부 상태를 가져오는 기능은 아닙니다.

- `발생시킬 상황`, `대상`, `상태`를 고르고 `상황 발생`을 누릅니다.
- 스캔 전체 완료, 다음 단계, 타일 방문, 화물 들기, 키카드 수집, 알람 종료, 신호 등을 가정할 수 있습니다. 멈췄거나 아직 활성화되지 않은 스캔은 완료할 수 없습니다.
- `1초 진행`, `5초 진행`으로 대기 블록 이후를 확인합니다. 게임과 같이 초당 20틱이며 신호로 시작되는 후속 이벤트는 다음 틱에 처리합니다.
- `조건 검사에 사용할 구역 내 플레이어`를 펼쳐 플레이어 존재 조건을 설정합니다.
- 문 개폐·각 면의 잠금, 타일 조명, 기믹 활성화, 목표 완료, 변수와 실행 기록이 표시됩니다.
- 스캔 목표를 완료하면 탈출 자동 활성화도 확인할 수 있습니다. 활성화된 탈출 스캔을 완료하면 임무 성공으로 종료합니다.
- `처음부터`는 모의 상태만 초기화합니다. 원본 프로젝트, 자동 저장, `.esfile`에는 모의 상태를 기록하지 않습니다.

모드의 `StageLogic` 처리 순서를 참고한 제작 도구이며 게임 서버를 구동하지 않습니다. 몹 전투·경로 탐색·실제 플레이어 수와 스캔 타이머·무작위 위치·문 충돌 및 조명 외형은 재현하지 않습니다. 스캔 진행과 알람 종료는 제작자가 수동으로 가정합니다. 현재 제거된 시설 터미널을 배치 가능하게 만드는 기능도 아닙니다. 마지막 실행 확인은 게임의 스테이지 검사·출발로 진행하세요.

## 기믹·이벤트 포함 복제

타일 속성의 `기믹·이벤트 포함 복제`를 누르고 배치 위치를 클릭합니다. R로 회전한 뒤 배치할 수도 있습니다. 타일만 복제하는 기존 `복제`는 그대로 사용할 수 있습니다.

새 타일에는 소속 기믹과 그 기믹을 목표로 하는 임무 목표, 해당 대상·문을 참조하는 블록 이벤트 및 간단 연결을 복제합니다. 새로운 ID를 부여하고 내부 문·스캔 단계·보급함·키카드·목표 참조를 새 대상으로 바꿉니다. 다른 타일·구역·전역 신호 이름·변수 이름 등 외부 참조는 유지합니다. 다른 타일에 지정한 스캔 단계도 그대로 그 타일을 참조합니다.

따라서 복제한 이벤트가 외부 문이나 전역 변수도 조작하도록 되어 있다면 함께 실행될 수 있습니다. 연결된 이벤트를 확인하고 필요에 맞게 수정하세요. 시작점이나 탈출 지점을 포함한 타일을 복제하면 하나만 있어야 하는 항목에 대한 스테이지 검사가 표시될 수 있습니다. 복제 작업 전체는 한 번에 실행 취소할 수 있습니다.
