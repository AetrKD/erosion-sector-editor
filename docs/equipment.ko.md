# Erosion Sector 장비 · 0.5.13

## 장비 선택 UI 0.5.11

화면 좌우 패널은 가장자리에서 같은 18 GUI 픽셀 간격을 사용합니다. 주·보조무기 전환은 화면 상단 중앙에 둡니다. 장비 목록에는 이름 오른쪽에 실제 인벤토리 아이콘이 표시됩니다. 근접무기 스킨도 18×18 슬롯과 해당 스킨이 적용된 아이템으로 표시하며, 다른 무기로 바꾸지 않습니다.

제목·구역명·설명에도 박스를 사용합니다. 화면을 열 때 왼쪽 목록은 왼쪽, 오른쪽 스탯은 오른쪽, 상단 선택은 위쪽, 하단 설명·슬롯은 아래쪽에서 240ms 동안 들어옵니다. 각 영역의 박스·글자·아이콘이 함께 이동하고, Esc로 나갈 때는 220ms 동안 같은 경로로 돌아갑니다. 아이템 선택 툴팁은 띄우지 않으며 스탯에 커서를 올렸을 때만 해당 수치의 역할을 설명합니다. 스킨·부착물에 마우스를 올리면 이름과 설명은 중앙의 고정 설명 칸에 표시합니다.

하단 패널은 화면 아래에서 18 GUI 픽셀 간격을 두고, 표시 가능한 행 수에 맞춰 높이를 줄였습니다. 각 행은 아이템 수에 맞춰 가운데 정렬합니다. 설명 칸은 48 GUI 픽셀 높이를 확보하고 줄바꿈하며 너무 긴 내용은 말줄임합니다.

하단 부착물은 배경과 테두리가 있는 하나의 패널입니다. 부착물 종류를 누르면 기존 슬롯 행은 아래로 내려가고, 호환 목록이 같은 패널 안으로 올라옵니다. 목록에 X 버튼은 없으며 Esc나 패널 바깥을 누르면 슬롯 행으로 돌아옵니다. 옵션이 많으면 페이지 버튼과 휠을 사용합니다. 부착물 제거는 해당 종류의 빈 슬롯 아이콘을 사용합니다.

모든 수치 아래에는 검정 배경·흰색의 얇은 2 GUI 픽셀 막대를 표시합니다. 부착물에 마우스를 올리면 복사한 총기에 해당 부착물만 적용하여 실제 TaCZ 수치를 계산합니다. 현재 장비는 바꾸지 않습니다. 현재 수치는 **변화량 텍스트의 너비 + 4 GUI 픽셀**만큼만 왼쪽으로 이동하고 변화량은 원래 오른쪽 끝에 표시합니다. 이동 중에도 두 텍스트는 겹치지 않으며 커서를 떼면 원위치로 돌아옵니다. 유리한 변화는 노란색, 불리한 변화는 빨간색이며 중량·조준 시간·지향사격 분산·반동은 감소가 노란색입니다. 막대의 변화 구간도 같은 색을 사용합니다. 그래프 범위는 ES 표시용 기준이며 이를 넘는 총기는 기준을 확장하여 함께 비교합니다.

드래그 회전·휠 확대와 선택 즉시 자동 저장 기능은 유지하되 안내 문구는 표시하지 않습니다. 화면은 Esc로 나가며 정상 HUD가 복원됩니다.

핫바 1번은 근접무기, 2번은 주무기, 3번은 보조무기, 4번은 도구입니다. 5~9번 핫바와 추가 보관 9칸은 자유롭게 사용하며 전체 18칸을 유지합니다. 슬롯 제한과 ES 장비 HUD는 서바이벌·모험 모드에 적용합니다.

## 근접무기 조작

0.5.13은 Better Combat 기반 좌클릭 유지 공격·우클릭 충전·단일 강공격·시간 초과 취소·무기별 강공격 모션을 지원합니다. 설정은 `es/melee/combat.json`에서 변경하고 `/reload`로 재적용합니다. [조작·설정·모션 안내](melee.ko.md).

## 장비 선택과 적용

ES 건축 탭에 **근접무기 선택기·총기 선택기·도구 선택기** 세 블록이 있습니다. 각 블록을 E키로 누르면 해당 장비 전용 화면이 열립니다. 근접무기 선택기는 무기와 전용 스킨, 총기 선택기는 주무기·보조무기와 호환 부착물, 도구 선택기는 도구를 선택합니다. 선택은 서버에 자동 저장되고 해당 선택기의 장비에 자동 반영됩니다. 근접무기·도구는 다른 종류의 선택 없이 적용하고, 총기는 주·보조 선택을 모두 마치면 함께 적용합니다. 적용·완료 버튼은 없으며 Esc로 나갑니다. 이미 고른 장비를 다시 누르면 저장된 구성으로 다시 적용할 수 있습니다. 스테이지 진입 전에는 네 역할을 모두 선택하세요. 완성된 선택은 스테이지 진입 때도 적용합니다. 별도 선택 없이 시험 출발하는 경우 현재 소지품을 사용합니다.

같은 총기의 부착물만 바꾸면 기존 총기·탄창·약실·예비탄을 유지합니다. 확장 탄창 해제로 용량을 초과한 장전탄은 예비탄으로 돌려주며 예비탄 상한을 적용합니다. 같은 근접무기의 스킨만 바꾸면 기존 내구도를 유지합니다. 바뀌는 슬롯의 이전 무기·도구는 제거합니다. 장비가 아닌 일반 아이템이 잘못 들어 있으면 자유 보관 칸 또는 복구 보관함으로 옮기고, 다른 슬롯의 보급품은 유지합니다. 같은 총기의 주·보조 중복 선택은 금지합니다.

명령어는 `/erosionsector equipment melee`, `/erosionsector equipment guns`, `/erosionsector equipment tool`이며 인수가 없으면 총기 선택기를 엽니다. 기존 `equipment_selector` 블록은 총기 선택기로 사용하며 새 블록 ID는 `melee_selector`, `tool_selector`입니다.

전체 화면을 덮는 배경·프레임·블러·암전 없이 월드를 그대로 보여 줍니다. **왼쪽 가장자리의 장비 목록 / 중앙의 3D 장비 / 오른쪽 가장자리의 스탯**으로 구성합니다. 중앙 장비 아래에는 설명을, 화면 하단에는 근접무기의 전용 스킨 또는 총기의 호환 부착물 슬롯을 표시합니다. 선택 중에는 기본 핫바·조준선·체력·TaCZ HUD·ES 자원 패널과 손에 든 장비를 숨기고, 화면을 나가면 정상 표시로 돌아옵니다. 개인 HUD 설정 파일은 바꾸지 않습니다. 가장자리 요소의 등장 이동·중앙 모델 회전·선택 변경 강조 효과를 추가했습니다. 중앙에서 마우스 왼쪽 버튼을 누른 채 끌면 회전하고 휠로 확대·축소합니다. 총기는 TaCZ의 실제 3D 모델과 선택한 부착물을 함께 표시합니다.

하단의 조준경·총구·개머리판·탄창 등 슬롯을 누르면 해당 슬롯의 호환 부착물 목록이 **180ms 동안 아래에서 올라옵니다.** 패널은 중앙 열 안쪽의 같은 자리를 사용하며 목록이 나타나는 동안 기존 슬롯 행은 내려갑니다. 왼쪽 목록·오른쪽 스탯·Esc 안내를 덮지 않습니다. 목록은 페이지 화살표나 휠로 넘깁니다. 부착물을 선택하면 패널이 닫히고 모델·스탯을 갱신합니다. Esc·바깥 클릭으로 패널만 닫을 수 있습니다. 슬롯은 설치된 TaCZ 원본 `GunAttachmentSlot`의 18×18 크기·기본 아이콘·장착 아이템 표시를 그대로 사용합니다. 부착물 목록도 원본 `InventoryAttachmentSlot`로 그리며 인벤토리와 같은 16×16 아이템 모델을 표시합니다. 해제에는 해당 종류의 빈 `GunAttachmentSlot` 아이콘을 재사용합니다. X 모양의 해제 버튼은 사용하지 않습니다. ES는 선택 콜백과 서버 검증만 연결하고 플레이어의 실제 인벤토리를 슬롯 미리보기로 덮어쓰지 않습니다.

설명은 고정된 중앙 박스 안에서 줄바꿈하며, 아이콘을 덮는 툴팁은 사용하지 않습니다. 스탯은 표시 행 높이를 자동으로 조절해 총기 12개 항목을 한 화면에 모두 표시합니다. 스탯 스크롤이나 페이지 버튼은 없습니다. 총기의 ‘피해량’은 근거리 기준이며 거리별·대상별 보정은 별도입니다. 선택한 스킨·부착물은 플레이어별, 무기별, 주·보조 역할별로 월드에 저장됩니다.

### 표시하는 성능 수치

스탯은 서버에서 제공한 실제 선택 장비와 동기화된 총기 데이터를 기준으로 읽으며 선택·부착물 후보가 바뀔 때만 계산합니다. 총기는 **피해량, 사거리, 연사 속도, 탄창 용량, 조준 시간, 정확도, 지향사격, 수직 반동, 수평 반동, 헤드샷 배율, 방어 무시, 중량**을 표시합니다. 탄창 용량을 제외한 수치·단위·소수 자릿수는 설치된 TaCZ의 성능표 API를 그대로 사용하며, 약실 한 발은 탄창 용량에서 제외합니다. 사거리는 TaCZ의 유효 사거리로 최대 비행 거리가 아닙니다. 정확도는 조준 정확도 %, 지향사격은 서 있는 상태의 비조준 분산값입니다. GUI 배율 2·3에서도 행 간격을 줄여 스크롤 없이 모두 표시합니다. Lua 스크립트의 상황별 보정이나 대상·거리·방어력까지 시뮬레이션하는 화면은 아닙니다.

근접무기는 주 손의 실제 무기 속성에서 기본 피해량·공격 속도·최대 내구도를 읽습니다. 인챈트·상태 효과·적 종류별 추가 피해는 별도입니다. 도구는 제공되는 실제 상태만 표시하며 ES 원형 도구는 준비 중임을 표시합니다. 총기 설명은 TaCZ의 설명 번역 키를 사용하므로 기존 ES 언어 파일의 같은 키로 문구를 바꿀 수 있습니다. 근접무기·도구에 아이템 설명(lore)이 있으면 사용하며, 없으면 기본 안내를 표시합니다.

인벤토리 등에서 총기에 커서를 올리면 **총기 이름·탄약 종류·실제 총기팩 이름**만 표시합니다. 설명·장전탄·등급·피해량·부착물 안내는 이 툴팁에서 제거하며 실제 총기 데이터는 바꾸지 않습니다.

## 전용 스킨과 부착물 등록

```text
minecraft/es/
├─ guns/                         기존 총기 설정
├─ attachments/tacz/<ID>.json     총기팩 부착물 선택 목록
└─ assets/melee/<무기>.json        무기별 전용 스킨 목록
```

### 총기 부착물

처음 로드할 때 설치된 TaCZ 총기팩의 공개 부착물 등록 파일을 자동 생성합니다. 이후 추가한 총기팩의 부착물은 같은 구조로 등록하세요. 다른 모드 JAR나 총기팩 원본은 수정하지 않습니다. `attachmentId`는 이미 설치된 총기팩의 ID여야 하며 파일 경로와 일치해야 합니다. 예를 들어 `tacz:scope_acog_ta31`이면 `attachments/tacz/scope_acog_ta31.json`입니다. 실제 존재하는 ID는 자동 생성된 파일을 참고하세요.

```json
{
  "version": 1,
  "attachmentId": "tacz:scope_acog_ta31",
  "enabled": true,
  "name": "4배율 조준경",
  "description": "장비 선택 화면에서 표시할 설명",
  "guns": ["tacz:ak47"]
}
```

`name`·`description`은 선택 사항이며 이름을 생략하면 TaCZ 이름을 사용합니다. `guns`를 생략하거나 빈 배열로 두면 호환되는 모든 총기에 허용합니다. 명시한 총기라도 TaCZ 원본이 호환을 허용해야 표시·장착됩니다. 부착물 종류는 원본에서 읽습니다. `enabled: false`나 파일 삭제로 목록에서 제외할 수 있습니다. **기본 구성**은 해당 슬롯의 외부 부착물을 해제하며 총기 내장 부착물은 유지합니다. 새 모델·성능의 부착물 자체를 만드는 기능은 TaCZ 총기팩에서 담당합니다.

### 근접무기 전용 스킨

무기를 고르면 **그 무기에 등록된 스킨만** 표시합니다. 다른 무기 아이템으로 교체하지 않습니다. 철 검·철 도끼에는 시설형·경비형 전용 모델을 예제로 포함합니다. 각 스킨은 원래 아이템·이름·공격력·속도·인챈트·내구도를 유지합니다.

`assets/melee/iron_sword.json` 예시:

```json
{
  "version": 1,
  "item": "minecraft:iron_sword",
  "skins": [{
    "id": "my_pack:iron_sword/blue",
    "name": "청색형",
    "description": "철 검 전용 스킨",
    "model": "my_pack:es_melee_skins/iron_sword/blue"
  }]
}
```

전용 모델은 리소스팩의 `assets/my_pack/models/es_melee_skins/iron_sword/blue.json`에 둡니다. 텍스처는 모델 JSON에서 참조합니다. 명시적 `elements` 모델은 `item/generated`·`item/handheld` 부모를 쓰면 요소가 사라질 수 있으므로 일반 모델 부모와 손·GUI용 `display` 변환을 지정하세요. 생성기는 `tools/generate-melee-skins.mjs`입니다. 다른 모드의 무기도 아이템 ID로 등록할 수 있지만 자체 전용 렌더러나 애니메이션을 사용하는 무기는 별도 연동이 필요할 수 있습니다.

서버는 선택 목록과 실제 아이템을 판정하고 클라이언트는 설치된 리소스로 외형을 표시합니다. 사용자 제작 모델은 모든 참여자가 리소스팩으로 설치해야 합니다. 누락된 모델은 원래 무기 외형으로 표시합니다. `es/assets`는 메타데이터 작업 폴더이며 리소스팩 자동 설치 경로가 아닙니다.

서버의 `/reload`로 등록 파일을 다시 읽습니다. 리소스팩 모델 수정은 클라이언트 리소스 재적용(F3+T)도 필요합니다. 잘못된 파일은 파일명·오류 위치와 함께 로그에 표시하고 이전 정상 등록을 유지합니다. 화면에도 설정 오류가 있음을 표시합니다. 삭제한 예제는 다시 생성하지 않습니다.

외부 모드 도구는 손에 들고 관리자 명령어로 등록할 수 있습니다.

    /erosionsector catalog tool 도구ID 표시이름

데이터팩의 erosionsector:tools 아이템 태그로도 도구를 분류할 수 있습니다.

## 화면 표시

우측 상단에 근접무기·주무기·보조무기·도구를 각각 별도의 작은 박스로 표시합니다. 각 박스의 첫 줄은 장비 이름, 둘째 줄은 남은 자원 퍼센트입니다. 박스 사이에는 간격을 두며 전체를 감싸는 배경은 없습니다. 이름과 상태는 오른쪽 정렬하며 선택 화살표는 별도의 고정된 칸을 사용합니다. 긴 이름은 정해진 폭 안에서 줄입니다. 0.5.12는 카드의 좌우 폭과 내부 여백만 줄이고 글자 크기·카드 높이·세로 간격·오른쪽 고정 위치는 유지합니다.

0.4.21부터 1~4번 핫바의 추가 색상 테두리와 ES가 별도로 그리던 선택 효과를 제거했습니다. 모든 핫바 칸은 기본 마인크래프트 테두리와 선택 표시를 사용하며, 인벤토리·상자 화면의 핫바 색상 테두리도 제거했습니다. 장비 전용 슬롯 제한, 빈 장비 칸의 용도 툴팁, 왼손 잠금과 우측 상단 장비 표시는 유지합니다.

글자 픽셀의 폭이 불균일해지는 것을 줄이기 위해 실제 화면의 정수 픽셀 배율로 그립니다. 기본 설정에서 GUI 배율 3·4는 글자 한 픽셀을 화면의 2×2픽셀로 표시합니다. 일반적인 9픽셀 높이 글자는 화면에서 약 18픽셀입니다. 0.5.12부터 박스 폭은 같은 조건에서 256픽셀(기존 352픽셀 대비 약 27% 축소)이며, 선택에 따라 폭이나 오른쪽 끝이 움직이지 않습니다. 화면이 작으면 배율을 낮추고 위치를 조정해 화면 안에 배치합니다.

- 총기: 예비탄 보유율. 장전탄·예비탄 개수는 기존 TaCZ HUD에서 확인합니다.
- 같은 탄종의 주·보조무기는 합산된 하나의 예비탄 풀과 한도를 표시합니다.
- 근접무기 등 내구도 장비: 남은 내구도 비율.
- 도구: 도구가 제공하는 잔량 비율. 잔량을 제공하지 않는 도구는 재사용 대기 중 또는 준비 중 상태를 표시합니다. 비율이 없는 장비는 —로 표시합니다.
- 현재 선택한 네 장비 중 하나에는 이름 왼쪽에 삼각형 화살표가 표시됩니다. 보급 팩 등 자유 슬롯을 선택하면 화살표를 표시하지 않습니다.

모드 설정 화면의 **장비 패널 크기**, 또는 erosionsector-client.toml의 equipment.hudScale로 희망 크기를 조절할 수 있습니다. 기본값은 0.5이고 범위는 0.25~1.5입니다. 실제 크기는 정수 픽셀 배율에 맞춰 단계적으로 바뀌며, 공간이 충분하면 가독성을 위해 글자 한 픽셀당 최소 2픽셀을 사용합니다. showHud, rightInset, topOffset도 유지합니다. 기존 highlightHotbar 옵션은 더 이상 사용하지 않습니다. 패널 크기는 체력·스태미나·TaCZ 총기 HUD의 크기에 영향을 주지 않습니다.

## TaCZ 총기 거치

TaCZ 원본 JAR와 총기팩은 수정하지 않습니다. ES 내부의 선택적 클라이언트 연동으로 기존 첫 핫바 거치 위치를 2번 주무기에, 기존 왼손 거치 위치를 3번 보조무기에 연결합니다. 총기팩에 거치 위치가 없으면 ES 기본 등·허리 위치를 사용합니다. 사용 중인 총기는 해당 거치 위치에서 숨깁니다. 근접무기·도구의 별도 거치 모델은 추가하지 않습니다.

팀원이 보이는 범위에 들어올 때와 장비·선택 슬롯이 바뀔 때 필요한 장비 표시 정보를 전달합니다. 부착물과 스킨은 유지하고 탄약 잔량처럼 자주 바뀌는 값은 거치 정보에서 제외합니다. 대기 중에는 네 슬롯의 참조와 선택 상태만 비교하며 전체 인벤토리나 탄종을 다시 계산하지 않습니다.

검증 대상은 NeoForge 1.21.1용 TaCZ 1.1.8-hotfix-r7입니다. TaCZ는 선택 의존성이며 포함하거나 수정하지 않습니다.

## 도구 구현 범위

설치형 센트리, 폭발 지뢰 설치기, 바이오 트래커의 원형 아이템을 ES 크리에이티브 탭과 도구 선택 목록에 추가했습니다. 현재는 슬롯·선택·표시를 위한 원형이며 설치·공격·폭발·탐지 기능은 아직 없습니다. 아이템 설명과 상태에 준비 중으로 표시합니다.

공통 도구 상태는 CUSTOM_DATA의 ESToolState에 remaining, capacity, cooldownUntil(월드 틱)을 제공하면 HUD에서 읽습니다. 상태를 읽는 과정은 아이템 데이터를 수정하지 않습니다. 실제 기능과 소모·회수·보급 규칙은 도구별 구현에서 연결합니다.


## 로비 탄약과 개조 제한

ES 로비 차원에서는 재장전할 때 예비탄을 소비하지 않습니다. 탄창과 재장전 애니메이션은 유지합니다. 로비 밖으로 나가면 즉시 일반 탄약 판정으로 돌아오며, 로비에서 사용하는 탄약은 임무용 예비탄 수치를 바꾸지 않습니다. ES 장비 HUD에는 로비 총기의 예비탄을 ∞로 표시합니다.

TaCZ 원본 개조 화면은 열리지 않으며, 기본 부착·해제·레이저 색 변경 요청도 서버에서 차단합니다. 총기 부착물은 ES 총기 선택기에서만 변경합니다. ES의 서버 검증과 공개 TaCZ API를 통한 적용은 유지합니다. TaCZ JAR와 총기팩 원본을 수정하지 않습니다.
