# 알람과 스캔 관리

게임 모드0.6.22 이상이 필요합니다. 알람 탭에서 적 테이블, 회차당 테이블 실행 수, 반복 횟수(0=무한), 회차 간격, 생성 타일, 스피커 반응 타일을 지정합니다. 선택한 타일에 실제 ES 알람 스피커를 설치해야 해당 타일의 동면 몹이 깨어납니다. 알람을 정지해도 이미 생성한 적은 남습니다.

스캔 탭에서 종류·위치·시간·인원·이탈 규칙을 지정합니다. 지도·단계 설정으로 타일 배치 화면에서 범위와 추가 단계를 편집합니다. 이탈은 일시정지/현재 단계 초기화/전체 초기화 중 선택합니다.

이벤트의 보안문 템플릿은 문 열기 시도→알람 시작→스캔 진행(전체 완료까지 대기)→같은 알람 정지→문 잠금 해제입니다. 스캔은 별도 종료 블록이 필요 없습니다. 기존 파일의 수동 스캔 제어는 해석 호환용으로 남습니다.

기존 .esfile의 기믹 ID와 참조 형식을 유지하므로 알람/스캔 설정은 다운로드·재불러오기로 보존됩니다. 타일/테이블을 삭제할 때 알람과 이벤트 참조도 수정해야 합니다.
