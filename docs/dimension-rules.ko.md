# 로비·임무 차원의 환경 규칙 · 0.5.4

`erosionsector:lobby`와 `erosionsector:mission`은 차원을 만들거나 다시 불러올 때 아래 규칙을 적용합니다. 기존 월드도 새 버전으로 다시 열면 적용됩니다.

| 항목 | 동작 |
| --- | --- |
| 자연 몹 생성 | 적대·동물 모두 비활성화. 자연 생성, 청크 생성 중 배치, 순찰 생성 경로도 거부합니다. |
| 추가 자연 출현 | 약탈자 순찰, 떠돌이 상인, 불면증에 의한 팬텀 출현을 비활성화합니다. |
| 낮·밤 시간 | 로비는 6000틱(정오), 임무는 18000틱(한밤중)으로 고정합니다. |
| 자연 날씨 | 맑은 상태로 시작하며 자연 날씨 변화가 없습니다. 오버월드의 비·천둥 상태를 물려받지 않습니다. |
| 몹의 지형 변경 | 크리퍼 등 몹 폭발의 블록 파괴, 엔더맨 블록 이동 등 mobGriefing 대상 동작을 막습니다. 폭발의 피해 판정은 유지합니다. |
| 불 | 자연적인 불 번짐과 블록 연소를 막습니다. |

알람·대기 몹·이벤트가 배치하는 몹은 계속 생성됩니다. 명령어·소환 알·스포너 같은 명시적 소환도 허용합니다. 기존에 존재하는 몹을 일괄 삭제하지 않습니다. 외부 모드가 자연 생성 타입을 사용하면 표준 NeoForge 생성 검사에서 거부되며, 생성 검사를 거치지 않는 임의 직접 엔티티 추가는 이 정책이 판별하지 않습니다.

멈추는 것은 낮·밤 시각입니다. 서버 게임 틱과 `gameTime`은 계속 흐르므로 스캔 진행도, 알람 웨이브·대기 시간, 몹 AI, 문 애니메이션, 장비·보급과 블록 엔티티는 계속 작동합니다. 무작위 블록 틱 속도, 레드스톤, 아이템 드롭, 인벤토리 보존, 난이도·피해 규칙은 기존 서버 값을 따릅니다.

## 적용 범위

Minecraft의 기본 GameRules는 여러 차원이 공유합니다. ES는 전역 설정 파일이나 서버의 원본 GameRules를 바꾸지 않고, 두 차원의 LevelData에만 별도 규칙을 제공합니다. 강제하는 8개 불리언 규칙을 제외한 값은 원본 규칙에서 읽으므로 관리자 변경도 계속 반영됩니다. 오버월드·네더·엔드·다른 모드 차원의 규칙은 유지합니다.

따라서 일반 `/gamerule` 명령이 표시하는 전역 값과 ES 차원에서 실제 사용하는 강제 규칙은 다를 수 있습니다. ES 차원의 시각은 `/time query daytime`으로 확인할 수 있으며 `/time set`으로 고정 시각을 바꾸지 않습니다.

별도 차원 데이터 파일을 사용자에게 만들도록 요구하지 않습니다. 정책은 재시작 시 다시 적용하며 사용자 총기·클라이언트 설정과 기존 블록 배치를 수정하지 않습니다.

## 검증

기본 GameTest 151개를 통과했습니다. 실제 ServerLevel 생성 경로에 적용된 LevelData, 고정 시각과 진행하는 게임 틱, 전역 규칙·오버월드 시간·날씨의 분리, 자연 생성 차단과 명시적 소환 허용, 실제 몹 폭발의 지형 보존을 검사합니다. 기존 스캔·알람·문·탈출 생명주기 검사도 포함합니다.

표시되는 개발용 클라이언트에서는 자동 생성, 로비·임무 차원 이동 전후의 서버·클라이언트 고정 시각, 실제 사망·부활, 저장 후 재접속의 규칙·건축물·위치 유지를 확인합니다. 검사용 클래스는 배포 JAR에서 제외합니다.
