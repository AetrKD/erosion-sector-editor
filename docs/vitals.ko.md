# 탐사 체력과 스태미너 · 0.4.6

서바이벌·모험 모드에 적용합니다.

- 최대 기본 체력은 **100**입니다. 기존 20 체력에서 전환할 때 남은 체력 비율을 유지합니다. 체력이 절반이었다면 50/100으로 바뀌며 매 틱 회복되지 않습니다.
- 원래 하트 위치(핫바 위 왼쪽)에 **HP 막대**, 원래 배고픔 위치(오른쪽)에 **ST 막대**를 표시합니다. 각각 현재 값과 최대값을 표시합니다. 보호막이 있으면 HP 수치에 더해 표시하고 테두리를 금색으로 표시합니다.
- 방어구, 산소, 탈것 체력, 채팅, 핫바와 총기 HUD는 기존 표시를 사용합니다. 살아 있는 탈것의 체력이 배고픔 자리를 사용하는 동안에는 기존 탈것 체력을 우선 표시합니다.
- 배고픔 소모·기아 피해·배고픔 기반 자동 회복을 사용하지 않습니다. 평화로움의 별도 자동 체력 회복도 끕니다. 월드의 자연 회복 게임 규칙 자체는 수정하지 않습니다. 보급 팩과 회복 효과는 작동합니다.
- 체력 보급 팩은 기존 설정인 **8 체력**을 회복합니다. 최대 체력이 100이므로 기본 팩은 전체 체력의 8%를 회복합니다. `config/erosionsector/supply.json`의 `healthPerPack`으로 조정합니다.
- 경험치 바와 레벨 숫자를 숨기고 플레이어 경험치·레벨을 0으로 유지합니다. TaCZ 자체 총기 속성은 변경하지 않습니다.

## 스태미너

최대 100, 실제 이동하며 달리면 초당 12 소모합니다. 서버가 이동량과 달리기 상태를 확인하므로 클라이언트는 스태미너 수치를 지정할 수 없습니다. 제자리에서 달리기 키만 누르는 경우에는 소모하지 않습니다.

달리기를 멈춘 뒤 1초 후부터 초당 18씩 회복합니다. 걸어도 회복됩니다. 0에 도달하면 달리기가 멈추고 20 이상 회복한 뒤 다시 달릴 수 있습니다. 탈진 중에는 막대가 황갈색으로 바뀝니다. 수치는 서버에서 보내고 클라이언트에서 보간하여 막대를 부드럽게 표시합니다.

리스폰하면 체력과 스태미너가 가득 찹니다. 차원을 이동해도 현재 스태미너를 유지합니다. 크리에이티브·관전 모드에서는 스태미너 제한을 적용하지 않고 원래 최대 체력과 HUD를 사용합니다. 다시 탐사 모드로 전환하면 남은 체력 비율을 보존합니다.
