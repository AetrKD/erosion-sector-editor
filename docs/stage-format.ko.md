# Erosion Sector 스테이지 파일 버전 2·3

0.6.0의 변수·목표 묶음·적/자원 배정·직접 성공 등 확장은 버전3을 사용합니다. 기본5개 JSON과 외부 NBT 구조는 유지합니다. [확장 계약과 사용법](stage-editor-rework.ko.md)을 먼저 확인하세요.

스테이지 하나 = 편집 프로젝트 하나 = .esfile 파일 하나입니다. stage 폴더는 챕터와 무관하게 .esfile을 평평하게 모읍니다. 파일명은 표시용이며 챕터·미션 정보는 내부 설정이 기준입니다.

## 외부 타일

기본 경로는 es/assets/tile/<타일셋>/<타일>.nbt입니다. 타일은 압축 묶음으로 변환하지 않으며 스테이지 안에도 복사하지 않습니다. 타일 식별은 assets/tile 폴더 기준 상대 경로 전체입니다. 연구소/복도.nbt와 공장/복도.nbt는 서로 다른 타일입니다. 절대 경로, 역슬래시, 빈 경로 조각, . 또는 .. 조각은 허용하지 않습니다. 경로 대소문자를 보존하며 일치하는 파일만 연결합니다. 이름이 같다는 이유로 다른 타일셋 파일을 선택하지 않습니다.

파일의 SHA-256은 수정 감지를 위한 값이며 이름을 대신하는 식별자가 아닙니다. 파일 내용이 바뀌면 자동 연결을 중단하고 편집기에서 명시적으로 설계도를 교체해야 합니다. 문 양면 접근 조건은 스테이지 설정에 보존합니다.

## 묶음 내부

.esfile은 표준 ZIP이며 아래 JSON 5개만 포함합니다. 타일 NBT·원본 base64·블록 점유 비트맵은 포함하지 않습니다.

- manifest.json: format=erosionsector-stage, version=2, tileRoot=assets/tile, 좌표 단위와 타일 규칙. status와 runtimeReady는 현재 프로젝트의 검사 결과를 저장합니다.
- stage.json: 스테이지 ID·이름·임무 설명, chapter의 ID·이름·설명, missionCode, 최소·최대 인원.
- tiles.json: 편집에 등록된 모든 타일의 ID·이름·분류·크기·문 연결구·양면별 조건. asset에는 reference(예: 연구소/복도.nbt), 이름·SHA-256·원본 통계만 저장합니다. 과거에 실제 NBT 없이 만든 타일은 asset=null일 수 있습니다. 기존 파일 읽기는 유지하지만 웹에서 새 빈 타일을 생성하지 않습니다.
- layout.json: 타일 배치·회전·소속 구역, 숫자 구역(rooms)·시설 묶음(zones), 문 연결. 각 배치의 areaCode는 a/b/c처럼 구역 안에서 구분하는 표시 이름입니다. 실제 참조는 placement.id이며 이름 변경·이동으로 바뀌지 않습니다. blockPosition은 실제 정수 블록 좌표이며 Y는 8의 배수입니다.
- logic.json: 기믹 위치·설정(gimmicks), 기존 간단 연결(links), blockFormat=1과 블록 이벤트(programs). 이벤트의 발생·조건·분기·반복과 실행 블록을 모두 저장합니다. 자세한 내용은 [블록 이벤트](event-blocks.ko.md)를 참고하세요.

스테이지 외부에 stage.json을 별도로 두지 않습니다. .esproject를 따로 만들거나 관리하지 않습니다. 이전 파일 형식의 이전 처리는 제공하지 않습니다.

## 편집기 동작

.esfile만 열어도 배치·챕터·미션·기믹을 편집할 수 있습니다. 타일 NBT는 ‘타일 폴더 연결’에서 사용자가 선택한 assets/tile 폴더에서 읽습니다. 원본 연결 전에는 누락 경고와 보수적인 저장 범위 충돌 검사를 사용하고, 연결 후 실제 비공기 블록으로 검사합니다. 파일·폴더를 웹 서버에 업로드하지 않습니다.

Chrome·Edge·Firefox에서 디렉터리 파일 입력으로 폴더를 읽습니다. 현재 저장은 브라우저 다운로드이며, 모드는 es/stage의 스테이지를 읽어 실행합니다. 스테이지 파일을 공유할 때는 참조하는 외부 assets/tile 폴더도 함께 전달해야 합니다.

스캔/탈출의 position 및 추가 단계 position은 정수 좌표 그대로를 중심으로 사용합니다(모드0.5.41 이상). 옛 centerAnchor 필드는 웹에서 다시 저장할 때 제거하며 게임에서는 무시합니다. 소수 좌표는 타일 내부에서 가장 가까운 정수로 맞추며, X/Z +0.5 오프셋은 사용하지 않습니다.
