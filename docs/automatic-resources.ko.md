# 자동 블록 리소스와 미리보기 회전

타일 미리보기에서 좌우 드래그 방향을 반전했습니다. 배치 지도 회전·타일 배치 방향·상하 회전은 변경하지 않습니다.

기본 제공 ES 모델은 웹에서 내려받으며, 설치 목록의 Minecraft 1.21.1 / Create 6.0.10 / Copycats+ 3.0.9 / Create Deco 2.1.3 / TaCZ 1.1.8-hotfix-r7 / Sable Player Ragdoll 0.7.5는 필요한 블록이 나타날 때 공식 배포 파일에서 자동 준비합니다. 수동 .esresources 연결은 필수가 아닙니다.

외부 원본을 공개 저장소/웹에 재배포하지 않고 Mojang/Modrinth 공식 CDN에서 브라우저가 직접 내려받습니다. 현재 설치 JAR와 일치하는 SHA-256/크기를 검증하며 서버로 전송하지 않습니다. 첫 사용에는 다운로드가 필요하고, 만든 모델/아틀라스는 브라우저에 저장해 다시 사용합니다. 데이터 삭제/버전 변경 시 다시 준비합니다. 이 다운로드 트래픽은 Vercel이 중계하지 않습니다.

블록 상태·모델·재질·Copycat 재질·타일 내부 연결 텍스처가 대상입니다. 모드 자체의 자바 렌더러, 엔티티/총기 애니메이션, 커스텀 동적 모델까지 실행하는 기능은 아닙니다. 블록을 추가하지 않는 최적화/UI 모드는 다운로드할 필요가 없습니다. 추가 리소스 연결은 별도 사용자 팩을 위한 선택 기능으로 유지합니다.

네트워크/공식 배포처가 일시적으로 실패하면 오류를 표시하고 다시 열어 재시도할 수 있습니다. 브라우저 저장 공간을 사용할 수 없어도 현재 미리보기는 표시되지만 다음 접속에는 다시 다운로드할 수 있습니다.

개발: 프로젝트 디렉터리에서 node tools/update-resource-sources.mjs <인스턴스 경로> [Minecraft client.jar 경로]로 설치 파일에 맞춰 공식 목록을 다시 생성합니다. 정확한 공식 파일이 없으면 중단하며 임의의 다른 버전으로 대체하지 않습니다. 외부 JAR/PNG/모델 원본은 공개 Git에 추가하지 않습니다.
