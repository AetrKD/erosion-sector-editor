# 인벤토리 · 0.4.20

생존·모험 모드에서 핫바 9칸과 내부 9칸, 총 18칸을 사용합니다. 방어구 칸은 유지하고 왼손 슬롯은 잠급니다. 크리에이티브에서는 기존 전체 인벤토리와 왼손을 사용합니다.

왼손은 인벤토리 클릭·드래그, 상자에서 손 교환 키로 이동, 일반 손 교환 패킷, NeoForge 아이템 자동 삽입으로 채울 수 없습니다. 기존 왼손 아이템이나 다른 모드가 직접 넣은 아이템은 정상 보관 칸으로 옮깁니다. 자리가 없으면 복구 데이터에 보관하고 이후 빈칸이 생길 때 복원합니다. 기존 네트워크 슬롯 번호는 유지하며, 개인 인벤토리에서 왼손 칸은 비활성 X 표시로 구분합니다. F 손전등은 그대로 작동합니다.

생존·모험 모드에서는 개인 인벤토리의 2×2 제작 칸, 결과 칸과 레시피 책을 제거합니다. 모드 전환 전에 제작 칸에 있던 재료는 유효한 인벤토리 칸으로 회수하며 공간이 부족하면 기존 아이템 복원 데이터로 보관합니다. 크리에이티브의 개인 제작과 설치한 작업대는 그대로 사용할 수 있습니다.

| 핫바 | 허용 아이템 |
|---|---|
| 1번 | 근접무기 |
| 2번 | 주무기 |
| 3번 | 보조무기 |
| 4번 | 도구 |
| 5~9번 | 자유 |

1~4번은 해당 종류의 장비를 교체할 수 있는 전용 칸입니다. 빈칸이어도 다른 종류의 아이템은 넣을 수 없습니다. 자유 칸에는 추가 무기도 넣을 수 있습니다. 무기를 주우면 비어 있는 지정 칸에 먼저 넣고, 일반 아이템은 자유 칸으로 넣습니다. 상자 이동, 드래그, 숫자키 교환과 일반 NeoForge 아이템 삽입에도 제한을 적용합니다.

개인 인벤토리와 일반 상자·보급 컨테이너 화면에서 내부 인벤토리를 한 줄로 표시합니다. 무기 슬롯은 테두리 색으로 구분하며 빈 슬롯에 마우스를 올리면 용도를 표시합니다. 다른 모드의 독자 화면은 기존 배치를 유지할 수 있지만 사용할 수 없는 인벤토리 칸에는 넣을 수 없습니다.

## 무기 분류

우선순위는 아이템 태그 → 장비 선택기에 등록한 분류 → 기본 분류입니다. TaCZ는 실제 GunId를 구분하므로 같은 총기 아이템 ID를 쓰더라도 다른 총까지 같은 분류로 취급하지 않습니다.

- 검·도끼·철퇴·삼지창은 근접무기입니다.
- 활·석궁은 주무기입니다.
- TaCZ의 `pistol`은 보조무기, 다른 총기 유형은 주무기입니다. TaCZ 데이터가 없거나 호환 API를 읽지 못하면 자동 분류를 추측하지 않습니다.
- 다른 모드의 무기는 기존 장비 카탈로그 명령으로 명시할 수 있습니다. 관리자가 무기를 든 채 입력하세요.

```text
/erosionsector catalog melee my_knife 칼
/erosionsector catalog primary my_rifle 소총
/erosionsector catalog secondary my_pistol 권총
```

분류는 클라이언트에도 동기화됩니다. 데이터팩을 쓴다면 `data/erosionsector/tags/item/melee_weapons.json`, `primary_weapons.json`, `secondary_weapons.json`에 아이템을 추가할 수 있습니다. TaCZ는 여러 총이 아이템 ID 하나를 공유하므로 개별 총 분류는 카탈로그를 사용하는 편이 정확합니다.

## 기존 아이템

이전 월드의 줄어드는 칸 또는 맞지 않는 무기 슬롯에 아이템이 있으면 유효한 빈칸으로 먼저 옮깁니다. 공간이 부족한 나머지는 플레이어의 저장 데이터에 보관하고, 이후 빈칸이 생기면 복원합니다. 복원 데이터는 죽음·재접속 때도 보존합니다. 새로 줍는 아이템은 18칸이 가득 차면 들어오지 않습니다.
