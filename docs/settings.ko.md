# ES 설정 · 0.4.24

메인 화면과 게임 일시정지 메뉴의 **설정** 버튼 옆에 **ES 설정** 버튼이 있습니다. 기존 설정 버튼 영역을 두 버튼으로 나누므로 다른 메뉴와 겹치지 않습니다. 모드 목록 → Erosion Sector → 설정도 같은 화면으로 연결합니다.

## 일반 설정

- 조명·밝기 효과: ES 시각 효과 통합 켜기/끄기.
- 손전등: 자체 조명 사용, 밝기와 거리.
- 총구 화염: ES 총구 효과 사용, 지속 시간, 밝기와 거리.
- 주변 어둠: 사용 여부, 광원 없는 곳의 밝기, 일반 조명 감쇠 기준, 야간 투시 허용.
- 장비 UI: 표시 여부, 크기, 오른쪽·위쪽 여백.
- 조작·키 설정: 현재 설치된 Minecraft 조작 설정 화면을 엽니다. 키 지정에서 Erosion Sector의 공통 상호작용과 손전등 키를 변경할 수 있습니다. 마우스 설정도 같은 조작 화면에서 엽니다.

설정값은 기존 `config/erosionsector-client.toml`에 저장합니다. 각 항목의 허용 범위를 검사하고, 되돌리기·초기화·완료 기능은 설치된 NeoForge의 기본 설정 UI를 사용합니다. 변경 사항은 실행 중 반영되며 완료로 해당 페이지를 닫으면 저장합니다. 일반 설정의 초기화는 개발자 설정과 devmod를 변경하지 않습니다.

총기·탄약·보급 파일 편집과 서버의 게임 규칙은 이 화면에 포함하지 않습니다. ES 설정은 개인 화면·조명·조작 설정을 다룹니다.

## 개발자 전용 메뉴

기본값은 꺼짐입니다. 아래 항목은 설정 화면에서 켤 수 없으며, `config/erosionsector-client.toml`의 **최상단, 첫 번째 [구역] 앞**에 있는 값을 직접 변경해야 합니다.

```toml
devmod = true
```

켜면 ES 설정에 **개발자 설정** 메뉴가 나타납니다.

- 손전등: 그림자 해상도, 내·팀원 그림자 갱신 상한, 그림자 계산 예산.
- 주변 어둠: 주변 광원 계산 예산.

`devmod = false`에서는 메뉴를 숨기고 개발자 페이지 직접 열기도 차단합니다. 켜진 메뉴를 사용 중 파일 설정을 끄면 해당 페이지를 닫습니다. 다른 일반 설정의 초기화로 devmod가 켜지거나 개발자 값이 초기화되지 않습니다. 이 옵션은 클라이언트 메뉴 접근을 제어하며 서버 관리자 권한을 부여하지 않습니다.

## 검증

실제 TaCZ 1.1.8-hotfix-r7 클라이언트에서 한국어 메뉴와 GUI 배율 2·3을 확인했습니다. 메인·일시정지 버튼의 위치와 겹침, 항목 이동, 실제 설정 변경·파일 저장, 개발자 값과 분리된 초기화, 기본 조작·키 설정 연결, devmod 비활성 접근 차단·활성화·실행 중 해제를 검사합니다. 검사는 별도 개발 월드와 설정만 사용하며 창을 숨깁니다.
