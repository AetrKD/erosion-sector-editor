# 보급 시스템 · 0.4.5

탄약 보급 팩(`erosionsector:ammo_pack`)과 체력 보급 팩(`erosionsector:health_pack`)은 Erosion Sector 크리에이티브 탭에 있습니다. 한 칸에 4개까지 겹칩니다. 5~9번 핫바에 놓고 손에 든 뒤 **E를 1초 유지**하면 자신에게 사용합니다. 조준선 아래 진행 막대가 차오릅니다. 키를 놓거나 다른 슬롯을 선택하거나 화면을 열면 취소됩니다. 한 번 사용한 뒤에는 키를 놓았다가 다시 눌러야 합니다. 우클릭으로는 사용되지 않습니다.

- 체력 팩: 기본 체력 8점(하트 4칸) 회복, 최대 체력 초과 불가.
- 탄약 팩: 2번 주무기와 3번 보조무기의 TaCZ 탄종 각각에 예비탄 보급. 탄창에 직접 장전하지 않습니다.
- 같은 탄종이면 하나의 예비탄을 공유하며, 최대량과 보급량은 두 총기 몫을 합산합니다.
- 체력 또는 예비탄이 모두 가득 찼거나 지원하는 총기가 없으면 팩을 소비하지 않습니다. 한 탄종만 부족하면 그 탄종만 채우고 팩 하나를 소비합니다.
- 예비탄은 플레이어 데이터에 저장되어 인벤토리 칸을 차지하지 않습니다. TaCZ 재장전의 실제 차감 지점에서 직접 소비하며 TaCZ의 예비탄 표시도 동기화합니다. 총기의 현재 탄창, 부착물과 재장전 애니메이션은 유지합니다.
- 서바이벌·모험 모드의 2·3번 슬롯에만 별도 예비탄을 적용합니다. 건축을 위한 크리에이티브 모드의 총기 탄약 동작은 그대로입니다. 예비탄은 총기에 담겨 거래되는 자원이 아니므로 총기를 옮겨도 다른 플레이어에게 복사되지 않습니다.
- 0.4.13부터 탄종·최대 예비탄·보급량은 장착 무기 변경 시 계산해 재사용합니다. 매 틱 전체 인벤토리를 훑는 탄약 동기화는 하지 않습니다. 재장전·보급 시에는 장착한 두 총기의 잔량 표시만 즉시 갱신합니다. 접속·부활·게임 모드 전환·설정 재적용 때도 갱신합니다.
- 일반 탄약 아이템은 이 예비탄에 자동 변환되지 않습니다. 이 기능은 TaCZ 1.1.8 hotfix-r7의 공개 API와 재장전 스크립트 호출부를 대상으로 검증했습니다. 다른 총기 모드는 대상이 아닙니다.

## 서버 설정

처음 서버/월드를 열면 다음 파일이 생성됩니다. 멀티플레이는 서버 설정을 따릅니다.

`es/guns/ammo.esgun` (JSON):

```json
{
  "version": 1,
  "defaults": {"maxReserve": 180, "refill": 45},
  "ammo": {
    "tacz:9mm": {"maxReserve": 120, "refill": 30}
  }
}
```

`ammo`의 키는 실제 TaCZ 탄종 ID입니다. `/erosionsector supply status`에서 장착 무기의 탄종 ID, 현재 예비탄, 최대량과 팩당 보급량을 확인합니다. 표에 없는 탄종은 defaults를 사용합니다. 동일 탄종 총기 두 정은 예를 들어 9mm 최대 240발, 팩당 60발을 공유합니다. 무기 교체로 최대량이 줄어들면 초과 예비탄은 제거됩니다. 현재 장착하지 않은 탄종의 기록은 보관하되 다시 장착할 때 최대량에 맞춥니다.

`es/guns/supply.json`:

```json
{"version": 1, "healthPerPack": 8}
```

수정 후 관리자 명령어 `/reload`로 적용합니다(0.4.8 이상). 데이터팩과 함께 `ammo.esgun`, `supply.json`을 다시 읽으며, 접속 중인 플레이어의 예비탄 최대량도 갱신합니다. 기존 `/erosionsector supply reload`도 사용할 수 있습니다. 잘못된 숫자나 형식은 오류를 표시하고 마지막 정상 설정을 유지합니다. 멀티플레이에서는 서버 측 파일을 수정해야 합니다. 총기 성능은 [총기 설정](guns.ko.md)의 총기별 .esgun에서 조절합니다(0.4.10 이상).

## 스테이지 편집기

보급 기믹의 **탄약 보급 팩 수량**, **체력 보급 팩 수량**에 고정 지급할 개수를 입력합니다. 게임에서 임무를 준비할 때 9칸 컨테이너에 추가합니다. 0은 추가하지 않음이며 기존 설계도 내용물을 유지합니다. 종류별 4개씩 쌓으므로 두 종류의 스택 합계가 9칸을 넘을 수 없습니다. 설계도에 들어 있는 물건이나 키카드가 사용할 자리도 남겨야 합니다. 무작위 추첨은 아직 사용하지 않습니다.
