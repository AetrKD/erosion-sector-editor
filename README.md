새 스테이지/불러오기, 타일셋별 폴더 가져오기, 실제 NBT 배치 미리보기, 층별 박스 배치, 구역 트리, 보급함·키카드·화물·알람·탈출 설정을 제공합니다. 모드는 .esfile과 외부 NBT를 읽어 스테이지를 구성하고 정해진 이벤트 블록을 실행합니다.

모드 0.4.26부터 시설 터미널 블록은 제거되었습니다. 기존 편집기에 남아 있는 터미널 기믹은 사용하지 마세요. 연결된 목표·이벤트가 있는 기존 스테이지는 다른 조건으로 수정해야 검사·출발할 수 있습니다. 스캔 탈출은 실제 블록 없이 지정 구역으로 판정합니다.

스테이지 설정에서 작성자, 챕터 이름, 자유 형식 난이도, 스테이지 이름과 설명을 편집합니다. 같은 챕터는 동일한 챕터 ID와 이름을 사용합니다. 새 항목이 없는 기존 파일도 빈 값으로 불러올 수 있습니다.

.esfile은 ZIP 안의 manifest.json, stage.json, tiles.json, layout.json, logic.json 다섯 설정만 포함합니다. NBT는 외부 es/assets/tile/타일셋/타일.nbt 경로와 SHA-256으로 참조하며 묶음에 넣지 않습니다. 스테이지 파일 자체가 프로젝트입니다.

## 로컬 실행

Node.js에서 node server.mjs를 실행하고 http://127.0.0.1:4173 을 엽니다. 앱 사용에 설치 단계는 필요하지 않습니다. 테스트에는 npm ci가 필요합니다.

- npm test
- npm run test:browser (로컬 서버 필요, 설치된 Edge 사용)
- npm run benchmark

## 현재 범위

미리보기는 실제 블록 좌표를 간략한 색상 육면체로 표시합니다. 모드별 복잡한 외형·텍스처·Create 동작은 게임에서 확인해야 합니다. 스테이지 조립 시에는 타일 크기와 문 위치를 사용합니다. 실제 비공기 블록 충돌을 검사하며 공기는 다른 타일을 지우지 않습니다.

파일은 브라우저에서 읽으며 서버에 업로드하지 않습니다. Chrome·Edge·Firefox 폴더 입력으로 가져오고 .esfile 저장은 다운로드를 사용합니다. 작업 폴더 직접 쓰기는 지원하지 않습니다. 브라우저 자동 저장은 주소별 복원본입니다.

기본 예시는 설계용이며 실제 건축물 NBT가 없습니다. 외부 기록 서버/DB 연동, 보급품 추첨 규칙, 정식 로비 장비 지급 흐름은 이 단계의 범위가 아닙니다.
